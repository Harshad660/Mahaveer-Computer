MAHAVEER COMPUTER - V3 CLOUD/ONLINE SOFTWARE

This package is a PHP + MySQL web application designed for normal shared hosting or XAMPP.

INSTALLATION:
1. Create a MySQL database, e.g. mahaveer_computer.
2. Open config.php and enter database host, database name, username and password.
3. Upload all files to your hosting public_html folder (or XAMPP htdocs/mahaveer).
4. Open install.php once. It creates the database tables and a default admin user.
5. Login:
   Username: admin
   Password: admin123
6. Change the password and shop settings after first login.

V3 FEATURES:
- Secure login session
- Dashboard
- Customer master
- Daily work / application tracking
- Service and rate master
- Bills and payment entries
- Pending payment calculation
- Status workflow: Pending / Processing / Ready / Delivered
- Printable payment receipt
- Daily/monthly reports
- CSV export
- Shop settings
- Responsive mobile + desktop UI

IMPORTANT:
This is a deployable starter application. For production use, enable HTTPS and change the default admin password immediately.
